## Problem
1. The Huddle opens on ranked/graded lanes (heat + NBA). To answer "who just opened?" Jack has to read
   scores first. Apollo's plain newest-first list answers it faster.
2. Apollo's list lacks what Prospector knows: real vs bot opens, open count across steps, owner, whether
   someone was already flagged/contacted, partner/company context, a suggested next step, one-click handoff.
3. "Most recent" is only as fresh as the last sync (manual on Render Free). The page doesn't say how fresh.

## Design decision

DECIDED — default tab "Live" (tabs: Live · Priorities · Done). Priorities = today's ranked view, unchanged.
- Top line: "Synced 12 min ago · Sync now" (Member+). If older than 2 hours, amber.
- Four numbers since last huddle, each a filter (drill rule): Replies · Clicks · Opened 2+ times · Flagged
  to me. Same counting rules as today (bot opens excluded).
- Filter chips: All · Replied · Clicked · Opened 2+ · Mine / Cyrus / Team (member list, not hard-coded) ·
  Sequence (dropdown). "Show bot opens (n)" toggle, off by default.
- ONE ROW PER PERSON, newest real activity first (not one row per event):
  name · company · title (if known) · owner dot · sequence short name + step ("Car Rental · Step 3") ·
  activity badges: ✉ sent · 👁 ×N real opens · 🖱 clicked · ↩ replied (reply badge wins, green) ·
  "last: 6:08 am" / "2 d ago" · already-handled markers (⚑ Flagged to Cyrus · ✓ Contacted today).
- One-line insight under the name, plain words, from existing data only, e.g.
  "Opened 3× since Tue, across steps 2–3 · clicked pricing link" or "Replied 6:08 am — not yet handled".
- Next step: one suggested action as text, from the existing NBA rules (no new scoring), e.g.
  "Call or LinkedIn today" / "Reply in thread" / "Wait — opened once". Shown as a quiet chip, not a grade.
- Row buttons (Member+, labeled words, compact on phone): Flag → (member menu, optional note; existing flag
  path, one open flag per prospect rule) · Mark contacted (existing, with undo) · LinkedIn (opens a LinkedIn
  people search for name + company in a new tab) · Open in Apollo (new tab) · ▸ expand.
- Expand: event timeline (sent / opened ×n with times / clicked which link / replied), the step's subject
  line, linked tasks (task-drawer chips), partner/company link if matched. Escape closes.
- Paging: 25 rows, "Load more". Search box (name / company).
- No Hot/Warm/Cold labels or scores on Live. They stay on Priorities.

DECIDED — keep
- Print agenda, Flagged-for-you lane (now also in the task drawer), Done recap → "Done" tab.
- All rules: Apollo read-only; no phone numbers; Viewer sees rows, no buttons.

PROPOSED / REVISABLE
- Stale-sync warning at 2 hours. 25 rows per page. Insight sentence wording.
