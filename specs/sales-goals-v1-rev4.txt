## Design decision

DECIDED — placement and shell
- Goals tab = first/default tab next to Overview | Daily Huddle (as decided for REV3).
- Right rail (shared RightRail component): View nav (4 views, each with a small count), Person
  filter, owner donut ("companies sequenced this week" by person), "Month at a glance" bars.
  Week picker in the header drives every view (Mon–Sun, America/Los_Angeles helper).
- Member colors: Jack #6F8CF0, Cyrus #C97626 (validated CVD-safe on dark); assigned per member
  from tokens, stable, never two the same. Status colors from tokens only.
- Donut/pie only for share-of-whole with ≤5 slices, center number + legend (counts, %). Rings for
  "% to goal". No dual axes.

DECIDED — view 1: Weekly report (default view)
- Header: "Seif & Jack weekly meeting · Week of <date>", Draft/Final pill with autosave time,
  donut "sections written n/12", button "Finalize & send to Seif" (finalize = freeze snapshot;
  sending by email is OUT of scope — button finalizes and opens the PDF).
- Commitments (Seif section 15) FIRST: each = text, measurable target, owner, link_target
  (a view or section), optional metric_key for live progress (e.g. outbound_audience →
  "4.52M of 5.5M"). Live progress where a metric exists; otherwise manual done/open.
  "Carry over unfinished" from last week (idempotent).
- Sections 1–14 as cards: number, Seif's label (exact), his "what I expect" line (muted), auto
  chips (value + source badge Apollo | App | Pipeline | Manual), optional status list, and a
  notes box (autosave). Section 2 is a status list (Completed / In progress / Blocked) carried
  forward weekly. Sections 6–9 and 12 show a link card to Pipeline (no duplicate tables).
  State pill per section: Written / Auto only / Empty.
- Seif's 11-row KPI table at the bottom: Last week | This week | Change | Target, source badge
  per row. Apollo rows computed from synced data; Pipeline rows from sales_opportunities
  (stage counts / sums as defined in sales-analytics-scorecard-v1); Meetings rows manual.
  Rows with no source show "—" (never invented).
- Finalize freezes a JSON snapshot (scorecard actuals, KPI table, commitments progress); a
  finalized week is read-only with "Reopen" (logged who/when).

DECIDED — view 2: This week
- Scorecard table: rows = outbound_audience (employees at companies sequenced that week),
  total_in_sequence, sequences_running, meetings_set (manual until calendar sync), open_rate.
  Columns = weeks of the selected month (selected week highlighted) + Month (actual vs target
  with a % ring). Each cell: actual, "of goal", thin bar, % colored good/warn/bad (≥90 / ≥60 /
  <60). Goals editable inline per week and per month; actuals read-only with source badge.
- To-dos grouped by category: title, steps (tick boxes), owner chip, contact chips ("w/ Seif"),
  progress "n of m", status computed (done / in progress / not started), status donut,
  "Carry over unfinished". Add to-do / add step inline.

DECIDED — view 3: Partners
- Three columns P1 (this week) / P2 (next 30 days) / P3 (60–90 days) + "Unprioritized" if any.
  Card: name, meeting status chip, champion. Click → expands: angle, their words (motto),
  watch-outs, sources, "Open first email" (shows stored draft; copy button), "Log meeting".
  Donut: partners by priority. Owner optional (null allowed; filter shows "Unassigned").

DECIDED — view 4: Companies
- "Sequenced in week N": companies that entered any sequence that week, with employees
  (headcount), cohort, sequenced-by (mailbox owner → member). Donut: employees reached by cohort.
  Show top 12 + "n more" expand. CSV export.
- Planned cadences: a simple list per future week (name, owner); add inline.

PROPOSED / REVISABLE
- Status thresholds 90% / 60%. Commitments allowed per week: soft guide 5–10.

      category text, contacts text[] default '{}', link_target text, metric_key text,
      target_value numeric.
  sales_week_goal_steps  id, business_id, goal_id FK (on delete cascade), text, done bool,
                         sort_order, done_at, created_at, updated_at
  ALTER sales_goals ADD: meeting_status text, champion text, angle text, motto text,

  sales_cadence_plan     id, business_id, week_start (Monday), name, owner_user_id, sort_order
  sales_week_report      business_id, week_start, status ('draft'|'final'), snapshot jsonb,

                         updated_by, updated_at; PK (business_id, week_start, section_key)
