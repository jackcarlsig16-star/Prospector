## Design — DECIDED (planner; REVISABLE values marked)
A1 One "who" control. The frame's Team | Jack | Cyrus control is the only one on Actions; Actions' own Mine | Team goes.
   Meaning: <person> = rows owned by that person; Team = everything; a new "Unassigned (n)" chip shows rows with no owner
   (so "mine" no longer hides that most rows belong to nobody). Default = the signed-in person. Remembered per browser.
A2 Sections = item-urgency bands (priority-v2 AUDIT §D), DataTable groups with counts, collapsible, remembered:
     NOW        replies (Apollo + campaign), overdue waiting-on, open flags < 5 d, reply/meeting with no to-do (reply_task)
                + any row overdue
     TODAY      interest follow-up (click / 2+ human opens), visited-no-touch, stale follow-up, campaign sends due,
                Focus 5, to-dos due today
     THIS WEEK  new website + Scout signals, research-or-drop, to-dos/waiting due later this week
     HOUSEKEEPING  set a date, duplicate, flag going cold, undated to-dos — collapsed by default
   Inside a band: company P (today's values until priority-v2 lands) → due → age. Sort headers work inside a band.
   The band comes from ONE function itemUrgency(kind, meta) in a new api/sales/priority.js (pure; reads nothing); the
   server sends band on every row; actionsRoutes stops using DEFAULT_PRIORITY / TIDY_PRIORITY to ORDER rows (the chip
   still shows the company P). reply_task and a positive reply are NOW regardless of company P (fixes audit S1/S19).
A3 Same action slots on every row, in the same place: [Primary] [Done] [More ▾]. Primary per kind: to-do → Done becomes
   the primary and slot 2 shows the due-date button; signal → Accept; Tidy → Accept; waiting → Got it; flag → Mark
   contacted; campaign send → Copy email (Sent in slot 2); campaign reply → Respond (opens the company window). Everything
   else per kind goes in More ▾ (Dismiss, Snooze, Nudge, Skip, Stop, statuses, Promote…) — nothing is lost, every existing
   action keeps its write and its Undo. Column widths fixed so the slots line up (N2).
A4 Adjust in place (Members; Viewers read-only):
   - Owner cell = a select on EVERY row kind. To-do / waiting / flag: PATCH owner_user_id. Signal / Tidy suggestion: picking
     an owner = Accept on that person's behalf (the to-do is created owned by them; the row becomes their to-do) — no new
     column, the existing accept writes with an owner parameter. Campaign rows: the contact's owner (seif-campaign route).
     Choices: each member + "Unassigned".
   - Due cell = a date button (to-do, waiting, campaign send): today / tomorrow / Friday / next Monday / pick a date / no date.
   - What to do (to-do, waiting): click the text in the row detail panel → edit in place (Enter saves, Esc cancels).
   - Every change: Undo for 10 s, same toast.
A5 Header tidy: the frame row keeps the "who" control, week navigator, Needs attention and Plan this week; the Actions
   filter row keeps Kind + Search + the Unassigned chip. Why column gets the width the second Who control frees; full text
   stays in the row detail (ebcbff4).
