== P6 RULES LEARNED (verbatim) =====================================================================================================
1. Replace, don't stack: a redesign spec names what it REMOVES before what it adds; the build deletes first.
2. Every fact once, every action once; a block with nothing to say does not render.
3. Each UI stage ships a side-by-side PNG (mockup | prod build) and a numbered deviation list; the planner compares before accepting - a report without the PNG is not accepted.
4. Mockups carry real data shapes (real counts, real names) - placeholder values hide layout failures.
